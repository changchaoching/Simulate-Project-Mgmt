四大核心決策項目 (Decision Variables)

目標團隊人數（Planned Headcount）：

「決定每週專案團隊要維持多少工程師規模，並衡量招募新人帶來的進場時間延遲與資深同仁的指導成本。」

排定每週工時（Scheduled Work Hours）：

「設定每位成員每週要投入多少工作時數，權衡短期衝刺增加產能與長期加班引發過勞及錯誤率飆升的代價。」

測試與品管強度（QA Intensity）：

「調配投入在代碼審查與測試驗收的精力比重，決定是要加快表觀進度，還是徹底抓出潛在缺陷以避免後期爆發返工。」

範疇變更政策（Scope Control）：

「面對客戶在專案進行中提出的功能追加需求，決定是要吸收擴充任務，還是堅決凍結範疇以守住預算與完工期限。」
